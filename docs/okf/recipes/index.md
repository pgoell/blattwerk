# Recipes

Whole sheets for common tasks. Each recipe is a doc that passes the schema; start from it and change the words, the seed or the text.

* [Plusaufgaben bis 20 mit Selbstkontrolle](plusaufgaben-bis-20.md): A heading, a name line, twelve addition sums to 20 with a fixed seed, and a self-check that lists the results shuffled.
* [Lernwörter mit Lineatur und Silbenbögen](lernwoerter-silbenboegen.md): Four Lernwörter on a two-line ruling, each word in grey to copy with a bow under each syllable.
