# Recipes

Whole sheets for common tasks. Each recipe is a doc that passes the schema; start from it and change the words, the seed or the text.

* [Plusaufgaben bis 20 mit Selbstkontrolle](plusaufgaben-bis-20.md): A heading, a name line, twelve addition sums to 20 with a fixed seed, and a self-check that lists the results shuffled.
* [Lernwörter mit Lineatur und Silbenbögen](lernwoerter-silbenboegen.md): Four Lernwörter on a two-line ruling, each word in grey to write over with a bow under each syllable.
* [Uhrzeiten lesen](uhrzeiten-lesen.md): A heading, a name line, and six clocks with full and half hours to read, the time written under each.
* [Zahlenmauern](zahlenmauern.md): A heading, a name line, and four Zahlenmauern with the sums above the given foot stones to fill in.
* [Suchsel mit Tieren](suchsel-tiere.md): A heading, a name line, and a word search of five animal words, running down, with the words printed under the grid.
